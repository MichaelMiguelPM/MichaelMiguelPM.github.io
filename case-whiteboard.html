Feature — Smart Matrix

A grid that never stopped evolving

Smart Matrix shipped in my first month at Brightidea and never stopped changing — from a static 2×2 grid to an AI-assisted, multiplayer scoring engine.

V1 launch — 2021

A 2-axis grid where dropped stickies scored automatically by placement.

A renewing enterprise account cited it as a reason to stay
Custom axes — 2023

Configurable X and Y labels, so any team could define its own prioritization criteria instead of a fixed Impact/Effort grid.

Reusable across use cases, not just one template
AI-assisted placement — 2025

AI plots linked ideas onto the matrix automatically by Impact vs. Effort, reading straight off the linked Pipeline records.

Removed the manual sorting step entirely
Collaborative Smart Matrix — 2026

A multiplayer-native rebuild letting a team score a matrix together in real time — in active development now.

Matrix work becomes a live, shared session
Feature — AI in Whiteboard

The largest bet: AI, built into the canvas

Epic BPD-34814 · 100+ linked issues — the largest Whiteboard initiative I owned.

1 Generate ideas

Prompt-based idea generation, dropped straight onto the board as stickies.

2 Cluster & summarize

Auto-group stickies by author, keyword or theme, then summarize the cluster.

3 Smart Matrix auto-placement

AI plots linked ideas by Impact vs. Effort — no manual sorting.

4 Generate & edit content

Generate images, fix grammar, or rewrite tone, in place.

5 PRD generation

Turn a sticky into a full Product Requirements Document.

6 Build an App with AI

Hands the generated PRD to ChatGPT / Replit, pre-filled, for instant prototyping.

Operating Model

Run like a product line, not a project

Three fronts, run in parallel for five years: keep the lights on, ship the next big bet, and connect the canvas back to the platform — daily triage, weekly exec "WB Update" reporting, and cross-functional design reviews.

Proof point — a live model swap under load

When dogfooding showed the original AI model underperforming, the team built an A/B toggle, validated GPT-4o-mini in production, and swapped models — without slipping the release.
